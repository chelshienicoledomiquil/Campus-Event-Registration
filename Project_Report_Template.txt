1. PROJECT THEME

Our project is a Campus Event Registration website. Its purpose is to let students register for an event using a simple webpage. The user enters their name, email, event date, event city, and number of attendees. The website also uses the Open-Meteo API to show the expected weather for the selected event date and city. After submitting the form, Google Apps Script creates a confirmation document, converts it into a PDF, and sends it to the email address entered by the user.

2. DATA PROCESS FLOW

The process starts when the user opens the website and fills out the registration form. The user enters their name, email, event date, event city, and number of attendees.

When the user clicks "Check Event Weather," the website uses the Open-Meteo geocoding API to find the city coordinates. It then uses the Open-Meteo weather API to get the weather forecast for the selected date. The weather information is displayed on the webpage.

When the user clicks "Confirm Registration," the form data and the weather information are sent to the Google Apps Script Web App. The Apps Script receives the data and creates a Google Doc containing the registration details. The Google Doc is converted into a PDF file. The PDF is then sent as an attachment to the email address provided by the user.

Data flow:
User -> Website Form -> Open-Meteo API -> Weather Display -> Google Apps Script -> Google Doc -> PDF -> User Email
